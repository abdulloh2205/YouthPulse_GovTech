# YouthPulse — Интеллектуальная система мониторинга и управления занятостью молодёжи (GovTech / NEXUS30)

## О проекте
YouthPulse — это инновационная платформа, разработанная для решения проблемы фрагментации данных о занятости молодёжи и оперативного выявления лиц категории NEET (Not in Education, Employment, or Training). Проект направлен на комплексную цифровизацию работы сходов граждан (махаллей) Мирзо-Улугбекского района. Централизация данных помогает муниципалитетам и профильным ведомствам адресно взаимодействовать с молодёжью, предоставляя им возможности для трудоустройства, обучения и предпринимательства.

## Ключевые возможности
- **Автоматический расчет NEET Risk Score (%)** фоновым аналитическим модулем для раннего выявления граждан, нуждающихся в поддержке.
- **Районный мониторинг территорий (Geo-Grid Dashboard)** с разделением по зонам риска (зеленая/желтая/красная) для визуального контроля уровня занятости в разрезе махаллей.
- **Персональные рекомендации и подбор мер поддержки** (направление на курсы «Ишга мархамат», выделение субсидий, организация стажировок).
- **Ролевая модель доступа** с разграничением полномочий (Сотрудник махалли / Районный хокимият).

## Технологический стек
- **Frontend**: HTML5, CSS3, Tailwind CSS, JavaScript (ES6+)
- **Backend**: Node.js, Express

## Установка и запуск

1. **Запуск Frontend:**
   В текущей версии MVP frontend автономен и может работать локально без сервера. Достаточно открыть файл `frontend/index.html` в браузере.

2. **Запуск Backend (для REST API):**
   ```bash
   cd backend
   npm install
   node server.js
   ```

## Перспективы масштабирования
Платформа закладывает фундамент для создания **B2B/B2G моста**, интегрируясь с предприятиями малого и среднего бизнеса района. Это позволит автоматизировать процесс быстрого найма, напрямую связывая работодателей с молодыми специалистами, сокращая дистанцию между безработным и потенциальным рабочим местом.
